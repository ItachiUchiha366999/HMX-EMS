# Phase 03.4 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Source: extracted and refined from `03.4-RESEARCH.md` "## Validation Architecture" section.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | bench-execute scripts (audit_*.py) + pytest scaffolds in `university_erp/tests/` |
| **Config file** | `frappe-bench/sites/common_site_config.json`; pytest via `bench --site university.local run-tests --app university_erp` |
| **Quick run command** | `cd /workspace/development/frappe-bench && bench --site university.local execute university_erp.scripts.audit_<X>.run` (where `<X>` is the audit script for the task's plan) |
| **Full suite command** | `cd /workspace/development/frappe-bench && for s in audit_reports audit_permissions audit_desk_ui audit_cross_app_links audit_workflows_e2e audit_report_source_schema; do bench --site university.local execute university_erp.scripts.$s.run; done` |
| **Estimated runtime** | ~120-300 seconds (full suite); ~10-60 seconds per individual audit |

---

## Sampling Rate

- **After every task commit:** Run the single audit script the task touched (e.g. `audit_workflows_e2e.run` after a plan-02 commit).
- **After every plan wave:** Re-run all 6 audit scripts in sequence; consolidated `AUDIT_REPORT.md` regenerated for the plan.
- **Before `/gsd:verify-work`:** Full suite must show 0 BROKEN findings; demo seed counts match baseline; `verify_education_removable.py` still exits 0.
- **Max feedback latency:** 60 seconds per task (single audit script); 5 minutes for wave-merge full suite.

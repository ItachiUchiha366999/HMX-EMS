# Phase 03.3.1 Workspace Fix Summary

One-liner: Routed all 71 forked Education doctypes into the correct university_erp workspaces by editing on-disk workspace JSONs, creating two new workspaces (Student Info, Admissions), and hiding the legacy Education workspace via DB so users see only the university_erp navigation.

## What Changed

### Existing workspaces extended (links appended, never deleted)

- **University Academics** (+28 links): added `Curriculum` (Program, Course, Topic, Course Schedule, Course Activity, Course Enrollment, Program Enrollment, Course Scheduling Tool, Program Enrollment Tool), `Assessments` (Assessment Plan/Group/Result/Criteria/Result Tool, Grading Scale), `Calendar` (Academic Year/Term), `Settings` (Education Settings relabeled "Academics Settings"), `Reports` (Course wise Assessment, Final Assessment Grades, Assessment Plan Status).
- **University Hostel** (+1 card + 1 link): `Houses` -> `School House` (relabeled "Hostel House").
- **Faculty Management** (+1 card + 2 links): `Instructors` -> Instructor, Instructor Log.
- **University Finance** (+2 report links inside existing Reports card): Student Fee Collection, Program wise Fee Collection. (Fee Collection Summary / Fee Defaulters were already present.)

### New workspaces created

- **University Student Info** (`university_student_info/workspace/university_student_info/university_student_info.json`): Students, Guardian Info, Tools, Other, Reports cards with the doctypes listed in the routing table (Student, Student Group, Student Log, Student Attendance, Student Leave Application, Guardian, Student Sibling, Student Attendance Tool, Student Group Creation Tool, Room, Student Status Log, University Alumni, University Announcement; reports: Absent Student Report, Student and Guardian Contact Details, Student Batch-Wise Attendance, Student Monthly Attendance Sheet).
- **University Admissions** (`university_admissions/workspace/university_admissions/university_admissions.json`): Admissions card (Student Applicant, Student Admission, Admission Cycle, Admission Criteria) and Configuration card (Student Category, Student Batch Name, Merit List, Seat Matrix).

### Education workspace hidden

Set `tabWorkspace.is_hidden = 1` for `Education` directly via:
`bench --site university.local execute frappe.db.set_value --args '["Workspace","Education","is_hidden",1]'`

**Why this approach (lightest-touch durable option):** The Education workspace JSON lives in the upstream `education` app — editing it would create app-fork divergence we don't want (we may uninstall `education` later). A Property Setter fixture on Workspace doesn't apply (Workspace is a transactional doc, not a customizable schema-only doc). The DB flag persists across `bench migrate` because Frappe's workspace sync only updates fields explicitly present in the JSON's schema-managed columns when `modified` is newer than DB; since the education app's `education.json` does include `is_hidden: 0`, a future migrate of *that* app could reset the flag. To guard against that, the durable mechanism is documented here: if `bench migrate` ever resets it, re-run the same `set_value` call (it can be wrapped in a `university_erp` `after_migrate` hook later if needed). For now the flag holds — verified post-migrate.

# Phase 03.3.1 Plan 01: Audit + Fork Scaffolding Summary

Wave 1 scaffolding for the Education app fork: built DOCTYPE_MAPPING.md (71-row source-of-truth table), authored fork_education_module.py with locked DOCTYPE_MODULE_MAP + fork_subset helper, added verify_education_removable.py removal gate, and laid down 8 Wave 0 test scaffolding files. Resolved both RESEARCH open questions in writing.

## What Was Built

### 1. Audit script + DOCTYPE_MAPPING.md
`scripts/audit_education_doctypes.py` walks `frappe-bench/apps/education/education/education/doctype/`, cross-references each directory against `DOCTYPE_MODULE_MAP`, and emits the definitive 71-row mapping table at `.planning/phases/03.3.1-.../DOCTYPE_MAPPING.md`. The script also resolves both open questions inline (reads quiz_question.json from both apps; reads both student_sibling JSONs and diffs field lists) and performs the D-04 destination-collision pre-flight.

Run output: `Rows: 71; Unmapped: 0; Destination collisions: 0`.

### 2. Fork script + removal verifier
`scripts/fork_education_module.py` exposes:
- `DOCTYPE_MODULE_MAP` (71 entries, mirrors DOCTYPE_MAPPING.md)
- `ARCHIVE_DOCTYPES` (8 entries)
- `copy_doctype_to_module(dt, mod, archive=False)` — copies edu doctype dir into destination module, strips tests/__pycache__, rewrites JSON module field
- `rewrite_imports_in_file(filepath)` — per-doctype-specific replace then catch-alls for `from education.education.` and `from education.utils`
- `fork_subset(doctype_names)` — plans 02/03/04 invoke this with their domain subset
- `run_full_fork()` — plan 06 calls this for completeness

`scripts/verify_education_removable.py` walks `university_erp/` (excluding `__pycache__`, `_archived`, `_archived_reports`), reports each `from education.` / `import education` violation, exits 1 if any. Pre-fork baseline = 6 (the override files); post-Wave-3 target = 0.

### 3. Wave 0 test scaffolding
Eight test files (all syntax-validated):
- `tests/test_education_import_integrity.py` — walks tree, asserts zero `from education.` imports
- `tests/test_override_collapse.py` — asserts overrides/ gone, hooks.py clean, forked Student.validate_enrollment_number / Fees.calculate_penalty present
- `tests/test_education_reports.py` — runs all 9 forked reports; fails only on ImportError
- 5 per-module `<module>/tests/test_education_fork.py` skeletons with empty `DOCTYPES = []` lists that plans 02/03/04 populate

## Open Questions Resolved (in DOCTYPE_MAPPING.md)

1. **Quiz Question table-name collision** — CONFIRMED: both Education and university_lms quiz_question.json declare `name="Quiz Question"` → both target `tabQuiz Question`. Resolution: Education's quiz suite (6 doctypes) is already a RESEARCH ARCHIVE candidate with zero usage in university_erp; the fork script copies them under `university_academics/_archived/` instead of `doctype/`, so the doctype is never registered and the table collision never materializes. university_lms's Quiz Question remains the sole owner.

2. **student_sibling vs student_siblings** — DISTINCT schemas:
   - `student_sibling` (8 fields): studying_in_same_institute, full_name, gender, column_break_4, student, institution, program, date_of_birth — the richer schema used by the Student doctype
   - `student_siblings` (3 fields): name1, gender, date_of_birth — sparse legacy table
   - Resolution: fork both into `university_student_info`; deprecation of `student_siblings` deferred to a follow-up after consumer audit.
